Merge Sort - Descrição

Problema Resolvido

Ordenação de uma lista de elementos comparáveis

Lógica Geral

  1. Divisão: Divide em duas metades
  2. Conquista: Ordena recursivamente
  3. Combinação: Une as metades ordenadas

Características

  • Algoritmo estável
  • Baseado em divisão e conquista
  • Complexidade consistente
  • Fácil de paralelizar

Pseudocódigo

MERGE-SORT(A, p, r) 1 if p < r 2 q = floor((p + r) / 2) 3 MERGE-SORT(A, p, q) 4 MERGE-SORT(A, q + 1, r) 5 MERGE(A, p, q, r) MERGE(A, p, q, r) 1 n1 = q - p + 1 2 n2 = r - q 3 let L[1..n1+1] and R[1..n2+1] be new arrays 4 for i = 1 to n1 5 L[i] = A[p + i - 1] 6 for j = 1 to n2 7 R[j] = A[q + j] 8 L[n1 + 1] = infinity 9 R[n2 + 1] = infinity 10 i = 1, j = 1 11 for k = p to r 12 if L[i] <= R[j] 13 A[k] = L[i], i = i + 1 14 else A[k] = R[j], j = j + 1

Classificação Assintótica

Big-Θ(n log n)

Tempo de execução limitado superior e inferiormente por c·n·log n

Big-O: O(n log n)

Limite superior: tempo nunca excede c·n·log n

Justificativa: Cada nível tem custo O(n) e há log n níveis

Big-Ω: Ω(n log n)

Limite inferior: tempo sempre ≥ c·n·log n

Justificativa: Mesmo no melhor caso, precisa percorrer todos os elementos

Complexidade de Espaço: O(n)

Arrays auxiliares de tamanho n para combinar as metades

Análise de Casos

Melhor Caso: O(n log n)

Cenário: Array já ordenado

Comportamento: Ainda divide e combina

Complexidade: Mantém O(n log n)

Pior Caso: O(n log n)

Cenário: Qualquer configuração

Comportamento: Sempre divide pela metade

Complexidade: Garantida O(n log n)

Caso Médio: O(n log n)

Cenário: Distribuição aleatória

Comportamento: Complexidade determinística

Vantagem: Previsibilidade total

Aplicabilidade Prática

✅ Vantagens

  • Estabilidade: Mantém ordem relativa
  • Previsibilidade: Complexidade consistente
  • Paralelização: Fácil de paralelizar
  • Ordenação externa: Para arquivos grandes

❌ Desvantagens

  • Memória: Requer O(n) espaço adicional
  • Overhead: Maior que algoritmos in-place
  • Constantes: Pode ser mais lento que Quick Sort

Classificação Computacional

Classe P: ✅ SIM

Problema solucionável em tempo polinomial O(n log n)

Versão NP: ❌ NÃO

Razão: Algoritmo determinístico

NP: Refere-se a problemas de decisão verificáveis em tempo polinomial por máquina não-determinística

NP-Completo: ❌ NÃO

Razão: Tem solução polinomial

Ordenação: Não é NP-completo pois tem solução eficiente

Conclusão

Merge Sort é um algoritmo eficiente e previsível para problemas práticos de ordenação
